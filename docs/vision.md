# “希望 Laibrary 是一个什么样的软件”

首先，它至少有富文本编辑能力，就如同它的 Item 数据系统所承诺的那样。

其次，它不能只处理富文本数据，还要能应对结构化数据。意味着这个系统至少要有类似于 Notion 的“数据库”那样的功能。能在“数据库”中新增一个项，项还能增删字段。不仅仅是 数字/字符串/时间 这样的基础字段，我们还要有 related 字段这种链接到另一个数据库的能力的字段。

之后，我们还得让数据库支持一种“不可变”的能力。如非必要，勿碰本体。而是派生出新的数据库，这个新数据库里创建的条目都必须有一个引用字段来表示其来自被派生数据库里的条目。显然这是为了 Gāng 准备的，Gāng要筛选数据，必要时还得修改数据，可总不能修改原数据，因为这可能会造成意外。

这种设计可能并不需要改动很多，甚至可以是靠某种约定来实现。也并不是说数据库全部都得 Immutable 化，而是需要这样的映射机制。默认还是能修改原数据的 —— 对于 Gāng 来说，修改原数据就是触发了变动，于是要再跑一遍 Gāng，去更新。
或者用技术术语来说，这种就是 Array.prototype.Map 函数。原数据不动，而是转换出新的数据出来。

我们要设计一组API，来方便第三方应用程序读写。至少是数据库要方便第三方应用程序读写。于是，我们得做：
- access token。让应用程序能访问数据库。并且access token会决定其具备什么权限（可读、可写、完全管理） 如果我们的项目进展足够顺利，甚至要支持具体的哪些字段可读可写、是否能让第三方程序增删字段、调整数据库的视图。
- 要有一个面板来集中管理 access token

还有就是，和 Notion 之流最大的不同，那就是 Item 要支持自定义 kind（语义类型），而不是无限增加核心 role。核心 role 是存储形态；kind 是插件内容类型。

比如我创建了“漫画库”的数据库，这时候我把 `entity + kind=manga` 的 Item 拖拽进去，数据库/卡片要能识别 kind=manga；如果视图采用“Icon”方式，就会用 manga kind 模块提供的 `inlineIcon`/Card 来呈现，而不是默认卡片。
这种思想类似于文件管理器的预览图：没注册格式就是默认「📄」，注册了 kind=manga 才显示漫画图标/封面。
继续是文件管理器的思想：在 Icon 视图下点击 Item，打开方式也不同；manga 用漫画阅读器，而不是默认页面编辑器。

我们也可以做一些强制视图，就是不管role是什么，它就是显示字段名。不会有别的，比如 Table/Gallery 视图，这些可以参考 Notion 里的样子。

**注意**，我们并不是实现一个大而全的 Notion 数据库，比如 Notion 的数据库甚至有 Kanban 的功能，我认为这个功能应该让第三方插件来做，让插件去调配 Item 去做。


# ”如果这个软件存在，我会如何使用，它提供了什么“

我会在家里的NAS上部署它，在家里是局域网访问，在外透过 Cloudflare ZeroTrust 来访问。

我会用它来完成所有的数据处理，连文件也是如此————未来会有一个“文件柜”连接器（当前 POC 未实现，后置）：它和某个目录/SMB 链接，投影外部文件；传统程序（如 VLC）可以直接打开。文件柜不是普通 file Item，也不同于内容寻址的 blob。

我还会和别人的 Laibrary 链接起来，能访问对方公开的 Item。这里需要赘述一下公共协作与分享的细节。

比如，我和A、B、C组合，主要不是访问对方公开的，而是创了 Public Space，在 Public Space 底下是公开的。这里可以设置权限和身份，谁有权可以访问哪些Item，谁是管理员，谁是只读。

谁储存Public Space？要决定一个主机 ———— 可是，所有人都要同步把 Public Space 拉过来，然后互相发送，类似 bittorrent 的思想。

然后，我们还要制作一种 ref database 的东西。也就是在 Local Space 上，可以新建ref数据库，这个ref数据库链接到Public Space上的数据库，有着所有的字段 —— 但你可以新增新的字段，可是新的字段不会反映在原数据库中。而且，属于原数据库的内容是只读的，你要修改得去原数据库里改。当然，我们做前端设计的得改成：这些字段都有锁的图标，然后要解锁了才可以修改————当然是调用的是修改原数据的API，而不是修改ref数据的API。

关于协作，我们不打算实现 CRDT 之类的东西，我们采用笨方法。也就是 LWW-Register：最后写入者胜，用时间戳决定。还有一层机制是，谁的光标落在此处。如果落在此处，就锁定，其他人不能改动。
